# Minecraft Rocket League

Fabric mod project for Minecraft Java Edition 26.3.

## Current prototype
- `/rl help` — show commands.
- `/rl car` — spawn a rideable vanilla minecart named Boost Fennec.
- `/rl ball` — spawn a small slime named Rocket Ball, launched in the direction you face.

These are temporary vanilla-entity prototypes. They are not yet the finished custom Fennec model, unlimited boost system, Rocket League ball physics, or mob-damage implementation.

## Build requirements
- Java 25
- Minecraft 26.3
- Fabric Loader 0.20.1+
- Fabric API 0.165.2+26.3
- Gradle 9.6.0

Run `gradle build`. The JAR should appear in `build/libs/`.
